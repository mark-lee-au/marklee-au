# New Project Prompt Template

Copy and fill in the text below when starting a new DATA, MAPS, GAMES, or LAB project.

```text
Read AGENTS.md and docs/index.md first.

I want to start a new project.

Working title: <title>
Initial category: <DATA, MAPS, GAMES, or LAB>
Question: <question>
Data source: <known source, or say research required>
Visual idea: <brief concept>

First, inspect the existing project system and relevant documentation.

Do not code immediately.

Use the staged collaborative workflow in docs/collaboration-workflow.md. Check current Codex usage before substantial work when available. Work only through the brief and direction stage, then stop for my review.

Create or update an execution plan under docs/exec-plans/active/ that covers:
- project question
- data source and licence
- expected fields
- data preparation
- visual encoding
- interactions
- mobile behaviour
- accessibility
- performance
- minimum publishable version
- later enhancements
- acceptance criteria

Then give me the plan for review.

After I approve the plan, work through these stages separately and wait for my approval between them:
1. source and data feasibility
2. local visual prototype
3. review and iteration loops
4. local release candidate and full QA
5. publication to main and live Cloudflare verification

Keep the project local and at idea/prototype status during review. Do not commit, push, merge, mark it published, or begin a later stage without my explicit approval. At each stage handoff, report the local route, decisions, open questions, checks run, files changed, and measured usage change when available.
```
