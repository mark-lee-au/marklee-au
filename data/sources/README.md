# Source and provenance notes

Commit one `<project-slug>.md` note per project. These notes are not copied into the website, but must be safe to publish in the repository. Never record credentials, signed URLs or private information.

Record dataset name, publisher, source URL, licence or reuse terms (including redistribution), retrieval method and timestamp, update frequency, date/geographic coverage, field definitions, processing script and command, transformations, units/timezone, validation and known limitations. Repeat per source when combining datasets.

Unknown facts must remain explicitly unresolved. [Pulse of Adelaide](pulse-of-adelaide.md) records the current research blocker without claiming a source exists.

Generate public metadata using the [metadata template](../../docs/templates/dataset-metadata.template.json), and expose verified attribution and methodology on the project page. See [governance](../../docs/data-governance.md).
