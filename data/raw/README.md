# Raw source data

Place permitted source downloads in `<project-slug>/`. Contents are ignored by Git except this README and are not website assets. Never put private employer data here; ignored files are not secure storage.

Record the source, reuse terms, retrieval timestamp, retrieval method and coverage in `../sources/<project-slug>.md`. Keep original downloads separate from transformations. Any small committed fixture needs a deliberate ignore exception and a documented licence and purpose.

See [data architecture](../../docs/data-architecture.md) and [governance](../../docs/data-governance.md).
